# E2E 测试案例:OCR 一键安装

> 测试 OCR 增强包的下载、安装、测试、异常处理全流程。
>
> 关联 spec:`docs/superpowers/specs/2026-08-12-p6-acceptance-and-docs-design.md` § 3.4.3

## 前置条件

- 启动器已启动,三个服务运行中
- OpenCLI 已连接(绿色 ✓)
- 网络连接正常(需下载约 200-500MB)
- 磁盘空间 > 1GB

## 测试步骤

### 步骤 1:点击下载安装 OCR

**操作**:在启动器面板"OCR 增强"卡片中,点"下载安装 OCR"按钮

**预期**:
- 按钮变为"安装中..."并禁用
- 进度条出现,从 0% 开始
- 状态标签变"安装中"(黄色)
- 日志卡片新增:"开始安装 OCR 增强包..."

### 步骤 2:观察下载进度

**操作**:观察进度条和日志

**预期**:
- 进度条平滑增长(0% → 30% → 60% → 90% → 100%)
- 日志依次显示:
  - "下载 paddleocr wheel..."
  - "下载 paddlepaddle wheel..."
  - "下载依赖 wheel..."
  - "下载 OCR 模型文件..."
  - "安装 wheel 到 venv..."
- 总耗时约 5-15 分钟(取决于网速)

### 步骤 3:安装完成

**操作**:等待进度条到 100%

**预期**:
- 进度条到 100% 后消失
- 状态标签变"已安装"(绿色)
- "下载安装 OCR"按钮变为灰色(已安装)
- "测试 OCR"按钮变为可点击
- 日志新增:"OCR 增强包安装完成"
- `.env` 中 `OCR_ENABLED` 自动设为 `true`
- `data/paddlex/official_models/` 目录有模型文件

### 步骤 4:测试 OCR

**操作**:点"测试 OCR"按钮

**预期**:
- 按钮变为 loading 状态(首次约 10-30 秒,模型加载较慢)
- 状态显示绿色 ✓
- 日志新增:"OCR 测试通过"
- 后端 `/api/v1/diagnostics/ocr` 返回 `ok` 状态

### 步骤 5:验证抓取中 OCR 生效

**操作**:
1. 点"打开网页"进入仪表盘
2. 发起一次小范围抓取(如 3 篇含图片的笔记)
3. 抓取完成后,查看推文详情

**预期**:
- 抓取过程中日志显示"OCR 识别图片..."
- 推文详情页显示图片提取的文字内容
- 活动信息提取准确率明显提高(对比未装 OCR 时)

## 异常案例

### 异常 1:网络中断

**前置**:安装过程中断开网络

**操作**:点"下载安装 OCR",下载到一半断网

**预期**:
- 进度条停止增长
- 10-30 秒后显示错误:"下载失败,请检查网络连接"
- 状态标签变"未安装"(红色)
- "下载安装 OCR"按钮恢复可点击
- 日志显示具体的下载错误(如 "Connection reset" 或 "Timeout")
- 可重新点按钮重试

### 异常 2:磁盘空间不足

**前置**:磁盘空间 < 500MB

**操作**:点"下载安装 OCR"

**预期**:
- 安装前检测磁盘空间
- 直接显示错误:"磁盘空间不足,需至少 1GB 可用空间"
- 不开始下载
- 状态保持"未安装"
- 日志显示:"磁盘空间检查失败:当前 <XXX>MB,需要 1024MB"

### 异常 3:重复安装

**前置**:OCR 已安装(状态为"已安装")

**操作**:尝试再次点"下载安装 OCR"

**预期**:
- 按钮为灰色不可点击
- 或点击后弹出提示:"OCR 已安装,如需重装请先删除 data/paddlex/ 目录"
- 不重复下载

### 异常 4:模型下载失败

**前置**:wheel 下载成功,但模型下载失败(HuggingFace 或 PaddleOCR 模型源不可达)

**操作**:点"下载安装 OCR"

**预期**:
- 进度条到约 80% 停止(wheel 装完,模型下载失败)
- 显示错误:"模型下载失败,请检查网络后重试"
- 状态标签变"部分安装"(黄色)
- 日志显示具体的模型下载错误
- wheels 已装好,重试时只下载模型部分

### 异常 5:OCR 测试失败

**前置**:OCR 已安装,但模型文件损坏

**操作**:点"测试 OCR"

**预期**:
- 按钮保持 loading 状态 30 秒后恢复
- 状态显示红色 ✗
- 提示:"OCR 测试失败,模型文件可能损坏"
- 日志显示具体的推理错误(如 "ModelNotFoundError" 或 "InferenceFailed")
- 建议用户删除 `data/paddlex/` 后重新安装

## 验收标准

- [x] 步骤 1-5 全部通过
- [x] 异常 1-5 全部按预期处理
- [x] 安装过程进度条平滑(不卡顿)
- [x] 安装失败后可重试
- [x] 安装完成后 `OCR_ENABLED` 自动设为 `true`
- [x] 测试 OCR 响应时间 < 30 秒(首次)
- [x] 卸载方法明确(删除 `data/paddlex/` + 设 `OCR_ENABLED=false`)

## 平台差异说明

| 平台 | OCR 包 | 大小 | 模型源 |
|---|---|---|---|
| macOS arm64 | `paddleocr-addon-<ver>-macos-arm64.zip` | 约 400MB | PaddleOCR 官方 |
| macOS x86_64 | `paddleocr-addon-<ver>-macos-x86_64.zip` | 约 400MB | PaddleOCR 官方 |
| Windows x64 | `paddleocr-addon-<ver>-windows-x64.zip` | 约 500MB | PaddleOCR 官方 |

启动器会根据当前平台自动选择对应的 OCR 增强包下载。
