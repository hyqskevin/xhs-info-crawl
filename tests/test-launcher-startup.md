# E2E 测试案例:启动器启动流程

> 测试启动器从双击到三进程运行、打开网页、退出的完整流程。
>
> 关联 spec:`docs/superpowers/specs/2026-08-12-p6-acceptance-and-docs-design.md` § 3.4.1

## 前置条件

- 干净的 macOS 12+ 或 Windows 10+ 环境
- 已下载 `xhs-info-crawl-<version>-macos.zip`(或 windows.zip)并解压
- 已安装 Google Chrome 并登录小红书
- 网络连接正常(首次启动需下载数据库初始化)

## 测试步骤

### 步骤 1:启动启动器

**操作**:
- macOS:右键 `xhs-info-crawl.app` → "打开" → 弹窗中点"打开"(首次)
- Windows:双击 `xhs-info-crawl/start.bat`

**预期**:
- 启动器窗口出现
- 窗口标题显示"小红书活动信息抓取系统 v<version>"
- 顶部 Top App Bar 显示程序名称和版本号
- 窗口背景为深色(M3 dark theme)

### 步骤 2:服务状态卡片显示初始化

**操作**:观察"服务状态"卡片

**预期**:
- API 行:黄色圆点 + "初始化中"
- Worker 行:黄色圆点 + "初始化中"(或"等待 API")
- Beat 行:黄色圆点 + "初始化中"(或"等待 Worker")
- 日志卡片显示启动日志

### 步骤 3:API 服务启动完成

**操作**:等待 5-10 秒

**预期**:
- API 行:绿色圆点 + "运行中" + 显示 `http://127.0.0.1:<port>`
- 日志卡片新增:"API 启动成功,端口 <port>"
- Worker 行开始初始化

### 步骤 4:Worker 服务启动完成

**操作**:继续等待 2-5 秒

**预期**:
- Worker 行:绿色圆点 + "运行中"
- 日志卡片新增:"Worker 启动成功"
- Beat 行开始初始化

### 步骤 5:Beat 服务启动完成

**操作**:继续等待 2-3 秒

**预期**:
- Beat 行:绿色圆点 + "运行中"
- 日志卡片新增:"Beat 启动成功"
- 三个服务全部绿色"运行中"

### 步骤 6:首次启动数据库初始化

**操作**(仅首次启动):观察日志

**预期**:
- 日志显示"首次启动,执行 alembic upgrade head"
- 日志显示"数据库初始化完成"
- 日志显示"admin 用户已创建"(或"admin 已存在,跳过")
- 总耗时约 5-10 秒

### 步骤 7:打开网页

**操作**:点底部"打开网页"按钮

**预期**:
- 系统浏览器打开 `http://127.0.0.1:<port>`
- 显示登录页
- 输入 `admin` / 密码(见 `.env` 中 `INITIAL_ADMIN_PASSWORD`,默认 `Admin@123`)
- 点击登录 → 进入仪表盘
- 仪表盘显示"发起抓取"卡片

### 步骤 8:退出程序

**操作**:点底部"退出"按钮

**预期**:
- 日志显示"正在停止所有服务..."
- 日志显示"API 已停止"、"Worker 已停止"、"Beat 已停止"
- 启动器窗口关闭
- 任务管理器中无残留 python 进程

## 异常案例

### 异常 1:端口 8000 被占用

**操作**:启动前用其他程序占用 8000 端口

**预期**:
- 启动器自动检测到 8000 被占用
- 日志显示"端口 8000 被占用,尝试 8001..."
- API 在 8001 端口启动
- "打开网页"使用 8001 端口

### 异常 2:数据库已存在(非首次启动)

**操作**:已有 `data/app.db` 文件再次启动

**预期**:
- 跳过数据库初始化
- 日志显示"数据库已存在,跳过迁移"
- 启动速度更快(约 3-5 秒)

### 异常 3:.env 文件不存在

**操作**:删除 `.env` 文件后启动

**预期**:
- 启动器从 `.env.example` 复制创建 `.env`
- 自动生成 `SECRET_KEY`(随机 32 字符)
- 自动生成 `INITIAL_ADMIN_PASSWORD`(随机 16 字符,写入 `.env`)
- 日志显示"已从 .env.example 初始化 .env"
- 日志显示"生成的 admin 密码:<密码>"

## 验收标准

- [x] 步骤 1-8 全部通过
- [x] 异常 1-3 全部按预期处理
- [x] 退出后无残留进程
- [x] 首次启动总耗时 < 30 秒
- [x] 非首次启动总耗时 < 10 秒
