## 1. 程序简介

本程序是一个**本地运行**的小红书活动信息抓取工具：

- 自动抓取指定城市、关键词、博主下的小红书笔记
- 用 AI 识别笔记图片 + 文字中的活动信息（名称、时间、地点、类型）
- 支持导出 **Excel / Markdown 周报**
- 支持**一键生成活动海报**
- 所有数据保存在你的电脑里，**不上传到任何服务器**

适用场景：本地生活/活动运营团队，每周收集本地活动信息，统一审核后发布。

## 2. 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | **macOS 12+** 或 **Windows 10+** |
| 浏览器 | **Google Chrome** 最新版（用于登录小红书） |
| OpenCLI | OpenCLIApp 桌面应用（程序内提供下载链接） |
| 磁盘空间 | 基础包约 200 MB；OCR 增强包另需约 1 GB |
| 内存 | 建议 8 GB 以上 |

**不需要单独安装 Python 或 Node.js**，程序已内置运行时。

## 3. 安装步骤

### 3.1 下载

1. 打开 [Releases 页面](https://github.com/hyqskevin/xhs-info-crawl/releases)
2. 找到最新版本（推荐 v0.6.0 及以上），下载对应平台的 zip：
   - **macOS（Apple Silicon / M1 / M2）**：`xhs-info-crawl-<version>-macos.zip`
   - **Windows**：`xhs-info-crawl-<version>-windows.zip`

### 3.2 解压

- **macOS**：双击 zip 解压，得到 `xhs-info-crawl.app` 和 `xhs-info-crawl` 文件夹。建议解压到 `~/Applications/` 或 `~/Documents/`。
- **Windows**：右键 zip → 解压到当前文件夹，得到 `xhs-info-crawl` 文件夹。

### 3.3 启动

- **macOS**：
  - **首次启动**：右键 `xhs-info-crawl.app` → 选择"打开" → 在弹窗中点"打开"（绕过 Gatekeeper）
  - **后续启动**：直接双击 `xhs-info-crawl.app` 即可
- **Windows**：
  - 双击 `xhs-info-crawl` 文件夹内的 `start.bat`

## 4. 启动器窗口与"打开网页"按钮

启动后会出现一个**桌面应用窗口**（macOS 在 Dock 上、 Windows 在任务栏），里面包含：

- **顶部**：程序名称和当前版本号
- **服务状态卡片**：API / Worker / Beat 三个服务（启动后会从"初始化中"变"运行中"绿色圆点）
- **OpenCLI 连接卡片**：检测结果 + 一键下载 OpenCLI 按钮
- **OCR 增强卡片**：OCR 包安装状态 + 一键下载按钮
- **日志卡片**：实时滚动日志（出问题先看这里）
- **底部**："打开网页"按钮（启动管理后台）+ "退出"按钮

> **启动器窗口本身不是数据展示页**，它只是开关。数据展示在管理后台浏览器页里。

## 5. 首次启动：自动初始化数据库

首次启动会自动初始化数据库（约 5-10 秒），期间请勿关闭窗口。
完成后会自动创建一个 **admin 管理员账号**（默认密码见下）。

如果数据库已经存在（例如升级或重装），不会重复初始化。

## 6. 配置 OpenCLI（必需）

OpenCLI 是程序与小红书浏览器交互的桥梁，**必须配置才能抓取数据**。

### 6.1 下载安装

1. 在启动器面板找到"**OpenCLI 连接**"卡片
2. 点"**下载 OpenCLI**"按钮 → 系统浏览器打开 OpenCLI 官方下载页
3. 下载并安装 OpenCLIApp 桌面应用
4. 打开 OpenCLIApp，按提示安装 Chrome 扩展

### 6.2 测试连接

1. 确保 **OpenCLIApp 已打开并运行**
2. 确保 **Chrome 已登录小红书**（<https://www.xiaohongshu.com>）
3. 回到启动器，点"**测试连接**"按钮
4. 等待 5-10 秒，显示绿色 ✓ + 版本号 = **连接成功**

### 6.3 连接失败排查

| 提示 | 原因 | 解决 |
|---|---|---|
| "未安装 OpenCLI" | 没装 OpenCLIApp | 点"下载 OpenCLI"安装 |
| "OpenCLIApp 未启动" | 装了但没打开 | 打开 OpenCLIApp 应用 |
| "未装 Chrome 扩展" | OpenCLIApp 里没装扩展 | 在 OpenCLIApp 里点"安装扩展" |
| "未登录小红书" | Chrome 没登录 xhs | 在 Chrome 里登录 xhs |
| 红色 ✗ + 错误信息 | 其他错误 | 查看日志卡片中的详细信息 |

## 7. 安装 OCR 增强（可选）

OCR 增强包让程序能识别**笔记图片中的文字**，提高活动信息提取准确率。不安装也能用，但只处理笔记文字部分。

### 7.1 安装

1. 在启动器面板找到"**OCR 增强**"卡片
2. 点"**下载安装 OCR**"按钮
3. 进度条显示下载进度（约 200-500 MB，取决于平台）
5. 进度条到 100% 后，状态变"已已安装"

### 7.2 测试

1. 点"**测试 OCR**"按钮
2. 等待 10-30 秒（首次加载模型较慢）
3. 显示绿色 ✓ = **OCR 工作正常**

### 7.3 注意事项

- OCR 增强包与主程序版本独立，可分别升级
- 安装 OCR 后会自动启用（`.env` 中 `OCR_ENABLED=true`）
- 卸载方法：删除 `data/paddlex/` 目录，并在 `.env` 中设 `OCR_ENABLED=false`

## 8. 登录管理后台

1. 确保三个服务都运行中，OpenCLI 已连接
2. 点启动器底部"**打开网页**"按钮
3. 系统浏览器打开 `http://127.0.0.1:<port>`（端口由启动器自动选择，通常是 8001 或 5173）
4. 登录页输入：
   - **用户名**：`admin`
   - **密码**：默认 `Admin@123`（首次登录后建议在"系统管理"里改密）

> **忘记密码怎么办**：打开 `xhs-info-crawl/.env` 文件，找 `INITIAL_ADMIN_PASSWORD=` 这一行；如果没改过，默认就是 `Admin@123`。

## 9. 日常使用：从抓取到周报

### 9.1 第一次用：先配基础数据

按顺序配：

1. **配置中心 → 城市**：新建你要抓的城市（如"宁波"、"上海"）
2. **配置中心 → 关键词**：新建关键词（如"市集"、"展览"）
3. **配置中心 → 博主**：手动加博主或 Excel 批量导入
4. **配置中心 → 小红书账号**（v0.5.0+）：加你登录 xhs 的 Chrome profile 名（用于多账号轮询）

### 9.2 发起一次抓取

进入"**仪表盘**"，底部"发起抓取"表单：

- **城市**（Row 1）：可不选 = 不限城市
- **时间范围**（Row 1）：一周内 / 两周内 / 一月内 …
- **关键词模式**（Row 2）：自定义关键词 / 关键词组
- **关键词**（Row 2）：输入或选组
- **博主模式**（Row 3）：博主列表 / 博主组
- **博主**（Row 3）：勾选具体博主或选组
- **操作账号**（Row 4）：从你加的小红书账号中选一个

点"**发起抓取**"按钮，任务进入队列。

## 11. 端口冲突处理

启动器会自动寻找空闲端口，无需手动配：

| 服务 | 默认范围 |
|---|---|
| 后端 API | `8001` ~ `8020` |
| 前端 | `5173` ~ `5199` |
| 状态服务 | `9000` ~ `9020` |
| OpenCLI daemon | 自动分配 |

- 如果默认端口被占用，**启动器自动 +1 寻找下一个空闲**（无需手动改）
- 选中的端口会写入 `.env` 并显示在启动器日志里
- 如果所有候选端口都被占，启动器会提示错误，需手动关闭占用进程或改 `.env`

## 12. 退出程序

- **正常退出**：点启动器底部的"**退出**"按钮 → 所有服务停止 → 窗口关闭
- **强制退出**：直接关闭启动器窗口 → 自动触发停止全部服务
- 退出后，任务管理器（macOS: 活动监视器；Windows: 任务管理器）中不应有残留的 `python` 进程

> **v0.5.7 改进**：之前版本经常出现"退出后端口还被占"的问题，v0.5.7 已修复。如果遇到，强制杀掉残留 `python` 进程即可。

## 13. 数据备份与升级

### 13.1 数据备份

所有数据都在 `xhs-info-crawl/data/` 目录下：

```
data/
├── app.db              ← SQLite 数据库（账号、城市、博主、活动…）
├── images/             ← 抓取到的笔记图片
├── exports/            ← 周报导出（Excel + Markdown）
├── posters/            ← 海报产物
├── celery/             ← Celery 队列
└── logs/               ← 运行日志
```

**备份 = 复制整个 `data/` 目录**到其他位置（外接硬盘、网盘、压缩包）。

### 13.2 升级

1. 下载新版 zip
2. 解压到**新位置**（不要覆盖！）
3. 把旧版 `data/` 整个复制到新版目录
4. 启动新版

数据格式在 v0.x 内向兼容；升级跨大版本前看 release notes。

### 13.3 重装 / 完全卸载

- macOS：把 `xhs-info-crawl.app` 和解压出来的 `xhs-info-crawl/` 文件夹一起丢进废纸篓
- Windows：删除 `xhs-info-crawl/` 文件夹即可

## 14. 常见问题 FAQ

### 14.1 macOS Gatekeeper 拦截

**现象**：双击 `.app` 提示"无法打开，因为无法验证开发者"

**解决**：右键 `.app` → 选择"打开" → 在弹窗中点"打开"。**只需首次操作**，后续直接双击即可。

### 14.2 找不到启动器窗口

**现象**：双击 `.app` 后什么都没有，菜单栏上也没图标

**解决**：

- 看 Dock 上有没有 xhs-info-crawl 图标
- 看 macOS 菜单栏顶部有没有 xhs-info-crawl 图标（点击显示窗口）
- 看活动监视器有没有残留 python 进程，全部杀掉重试

### 14.3 OpenCLI 一直连接失败

**排查**：

1. 确认 OpenCLIApp 应用已打开（在 Dock 或任务栏可见）
2. 确认 Chrome 已登录小红书
3. 在 OpenCLIApp 中检查 Chrome 扩展是否已安装并启用
4. 查看启动器日志卡片，寻找具体错误信息
5. 重启 OpenCLIApp 和 Chrome 后再试

### 14.4 OCR 安装失败

**排查**：

1. 检查网络连接（OCR 包从 GitHub Release 下载）
2. 检查磁盘空间（需约 1 GB）
3. 查看启动器日志，寻找下载错误
4. 重新点"下载安装 OCR"重试

### 14.5 端口全部被占用

**现象**：启动器提示"端口 8001-8020 全部被占用"

**解决**：

1. 关闭占用端口的程序（如其他开发服务器）
2. 或手动编辑 `.env` 文件，修改 `API_PORT` 为其他可用端口（如 9000）
3. 重启程序

### 14.6 抓取任务卡住 / 失败

**排查**：

1. 检查 Chrome 是否仍登录着 xhs（Cookie 没失效）
2. 检查是否触发 xhs 风控（任务会自动暂停并保留 Chrome 页面）
3. 看"任务日志"页面点详情，查看错误信息
4. 看启动器日志卡片

### 14.7 忘记 admin 密码

- 打开 `xhs-info-crawl/.env` 文件
- 找到 `INITIAL_ADMIN_PASSWORD=`，记录密码
- 如果没改过，默认密码是 `Admin@123`
- 还可以在"系统管理"页用其他管理员账号重置密码

### 14.8 升级后数据还在不在

- 数据库、图片、配置全在 `data/` 下
- 升级新版时**保留 `data/` 目录**就能保留所有数据
- 跨大版本升级可能需要执行迁移脚本，看 release notes

### 14.9 抓到的活动数太少

- 关键词 / 博主组太少
- 时间范围太短（默认一周内）
- 城市限制太死（可不选城市）
